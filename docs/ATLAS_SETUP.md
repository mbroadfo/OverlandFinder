# MongoDB Atlas Setup - OverlandFinder

Quick setup guide for creating the `overland-finder-dev` Atlas project and M0 free cluster.

## 📋 Overview

- **Project**: `overland-finder-dev` (NEW - don't use mrb-dev)
- **Cluster**: `overland-finder-cluster`
- **Database**: `overland_finder`
- **Region**: East US (Azure - matches Terraform)
- **Tier**: M0 Free (512MB)

## 🚀 Step-by-Step Setup

### Step 1: Create New Project

1. Go to [cloud.mongodb.com](https://cloud.mongodb.com)
2. Click organization dropdown (top-left) → Verify you're in "My Mongo Horde"
3. Click **"New Project"** button (top-right)
4. **Project Name**: `overland-finder-dev`
5. Click **"Create Project"**

### Step 2: Create M0 Cluster

1. Click **"Build a Database"**
2. Select **M0 FREE** tier
3. **Cloud Provider**: Select **Azure** (instead of AWS)
4. **Region**: Select **East US** (matches your Terraform location)
5. **Cluster Name**: `overland-finder-cluster`
6. Click **"Create Cluster"**

⏱️ Wait 2-5 minutes for cluster provisioning.

### Step 3: Create Database User

During setup, Atlas will prompt for a user. If not:

1. **Security** → **Database Access** → **Add New Database User**
2. **Authentication Method**: Password
3. **Username**: `overland_app`
4. **Password**: Click "Autogenerate Secure Password" → **COPY IT IMMEDIATELY**
   - Or create your own (32+ characters recommended)
5. **Database User Privileges**:
   - Built-in Role: **Read and write to any database**
6. Click **"Add User"**

🔒 **CRITICAL**: Save the password now - you won't see it again!

### Step 4: Configure Network Access

1. **Security** → **Network Access** → **Add IP Address**
2. Click **"Allow Access from Anywhere"**
   - IP: `0.0.0.0/0`
   - Comment: `Azure Container Apps (dynamic IPs)`
3. Click **"Confirm"**

⚠️ Azure Container Apps use dynamic IPs, so we need open access. Security is enforced through:
- Strong password (32+ chars)
- Azure Key Vault (no hardcoded secrets)
- Managed Identity for Azure services

### Step 5: Get Connection String

1. **Database** → **Connect** → **Drivers**
2. **Driver**: Node.js (or any - doesn't matter)
3. **Copy** the connection string:

```
mongodb+srv://overland_app:<password>@overland-finder-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

4. **Replace** `<password>` with your actual password from Step 3

**Example Full URI**:
```
mongodb+srv://overland_app:Xy9k2mP8n4Qr7vL1sW6jH3dF5gT0zB9c@overland-finder-cluster.abc123.mongodb.net/?retryWrites=true&w=majority
```

### Step 6: Create Database (Optional - Auto-Created)

The database `overland_finder` will be auto-created when your app first writes data, but you can create it now:

1. **Database** → **Browse Collections**
2. **Create Database**
3. **Database Name**: `overland_finder`
4. **Collection Name**: `deals` (first collection)
5. Click **"Create"**

## 📝 Update Terraform Configuration

1. Open `infrastructure/terraform/terraform.tfvars`
2. Add your MongoDB URI:

```hcl
# MongoDB Atlas Connection (M0 Free - East US)
mongodb_uri = "mongodb+srv://overland_app:YOUR_PASSWORD_HERE@overland-finder-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority"

# SMTP Configuration (for SMS via email gateway)
smtp_username = "your_verizon_number@vtext.com"  # e.g., 3035551234@vtext.com

# Azure AI Foundry (GPT-4)

# SMS Recipient

```

## 🔐 Security Notes

**What's Secure:**
- ✅ Password: 32+ character autogenerated password
- ✅ Secrets stored in Azure Key Vault (Terraform stores them there)
- ✅ Managed Identity: Container Apps auth to Key Vault (no hardcoded creds)
- ✅ `terraform.tfvars` in `.gitignore` (never committed)

**Why Open Network (0.0.0.0/0) is OK:**
- Azure Container Apps don't have static IPs
- Strong auth (32+ char password) > IP whitelisting with weak password
- MongoDB Atlas has built-in DDoS protection and rate limiting
- Can add VNet integration in Phase 9 if needed

## 🎯 Next Steps

After Atlas setup is complete:

```powershell
# Navigate to Terraform directory
cd infrastructure/terraform

# Copy example config (if not done yet)
cp terraform.tfvars.example terraform.tfvars

# Edit terraform.tfvars with your MongoDB URI and other secrets
code terraform.tfvars

# Initialize Terraform
terraform init

# Preview changes
terraform plan

# Deploy infrastructure (~7-8/month)
terraform apply
```

## 📚 Collections (Phase 1)

These will be created by your Python code in Phase 1:

```javascript
// Collections to be created
db.deals {
  _id: ObjectId,
  vin: String (unique),
  listing: { title, url, price, mileage, location, ... },
  evaluation: { value_score, market_price, discount_pct, ... },
  timestamp: ISODate,
  source: String  // "facebook", "ebay", "craigslist"
}

db.scrape_history {
  _id: ObjectId,
  url: String (unique),
  scraped_at: ISODate,
  source: String
}

db.user_favorites {
  _id: ObjectId,
  deal_id: ObjectId,
  starred_at: ISODate
}
```

**Indexes** (Phase 1):
- `deals`: `{ vin: 1 }` unique, `{ value_score: -1 }`, `{ timestamp: -1 }`
- `scrape_history`: `{ url: 1 }` unique, `{ scraped_at: -1 }`
