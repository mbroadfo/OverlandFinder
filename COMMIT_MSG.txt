Initial commit: Overland Finder v1.0.0 - AI-powered vehicle deal finder

# Summary
Complete AI agent platform for finding and evaluating undervalued overlanding
vehicles using Microsoft Agent Framework. Includes vehicle knowledge database,
value evaluation engine, AI agent with natural language interface, SMS 
notifications via Verizon gateway, and VS Code debugging integration.

# Features
- Vehicle knowledge database with 12 overlanding platforms (Wrangler, 4Runner, 
  Tacoma, Land Cruiser, GX470/460, LX470, Xterra, Frontier, Bronco, Colorado)
- Value evaluation scoring engine (0-100 scale based on discount%, platform 
  quality, budget ratio, mileage, and red flags)
- AI agent with 4 natural language tools: get_target_vehicles, 
  get_vehicle_knowledge, evaluate_deal, get_saved_deals
- HTTP server mode for production deployment (port 8087)
- SMS notifications via Verizon email-to-SMS gateway (daily updates, 140 char limit)
- Daily monitoring with 24-hour enforcement
- VS Code debugging configurations (.vscode/launch.json, tasks.json)
- Comprehensive documentation (README.md, SMS_SETUP.md)

# Technical Stack
- Python 3.13.12
- Microsoft Agent Framework (agent-framework-azure-ai 1.0.0b260107)
- Azure AI Agent Server (azure-ai-agentserver-agentframework 1.0.0b10)
- Azure Identity with DefaultAzureCredential
- Web scraping: beautifulsoup4, requests, selenium, webdriver-manager
- Data processing: pandas
- Scheduling: APScheduler, schedule
- Development: debugpy, agent-dev-cli
- Type checking: Pylance (basic mode)

# Configuration Required Before Running
1. Set FOUNDRY_PROJECT_ENDPOINT in .env (Azure AI Foundry project)
2. Set FOUNDRY_MODEL_DEPLOYMENT_NAME in .env (deployed model name)
3. For SMS: Set SMTP_USERNAME and SMTP_PASSWORD (Gmail App Password)
4. For SMS: Set ENABLE_SMS_NOTIFICATIONS=true when ready
